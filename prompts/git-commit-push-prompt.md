# これまでの作業をcommitしてGitHubにpushする

このリポジトリは最初のコミット（`6cd946f Initial commit from Create Next App`）以降、
一度もcommitされていません。数週間ぶんのリデザイン作業が全て未コミットの
working treeとしてしか存在しておらず、しかもそのバックアップを担っているDropboxが
`.next`に同期の競合を起こし続けている状態です。

**まずは作業を確実に保全するため、commitとpushをお願いします。**

---

## 1. commit前の確認

- `git status`で、意図しないファイルが含まれていないか確認してください。特に:
  - `.env.local`（anonキーが入っています）が`.gitignore`で除外されているか
  - `.next` / `node_modules` が除外されているか
  - Dropboxが生成した競合コピー（`* (…の競合コピー…)` のような名前のファイル）が
    紛れ込んでいないか。`find . -name "* (*" -not -path "./node_modules/*"` で確認できます
- 除外漏れがあれば`.gitignore`に追加してからcommitしてください

## 2. commitの分け方

全部を1コミットにまとめず、**意味のある単位で分けてください**。
後から履歴を追えることの方が、コミット数を減らすことより大事です。目安として:

- 客側リデザイン（`/order`系・`/cart`・`/complete`）
- スタッフ側の共通基盤（`components/admin/nav/`・`AdminPageShell`・`TopBar`等）
- 厨房・レジのリデザイン
- メニュー管理・カテゴリ管理のリデザイン
- テイクアウト受渡の新規実装
- デザイントークン（`design-tokens.css`・`typography.css`）
- SQLマイグレーション（`supabase/*.sql`）
- ドキュメント（`docs/handoff.md`・`prompts/`）

実際の変更内容を見て、この分け方が実態に合わなければ調整して構いません。
分け方の方針だけ一言報告してください。

コミットメッセージは日本語・英語どちらでも構いません。既存の1件目が英語なので
英語に揃える方が自然かもしれませんが、お任せします。

## 3. push

リモートリポジトリが未設定の場合は、**その時点で一度止めて報告してください。**
GitHubにリポジトリを作る操作は天真さんが行います（publicかprivateかの判断もあるため）。

設定済みであればそのままpushしてください。

---

## 4. push後にやりたいこと（参考）

pushが完了したら、プロジェクトをDropboxの外（`~/Developer/Orderly`など）に移すことを
検討しています。そうすれば`.next`の同期競合・`node_modules`の同期負荷・`.git`の
破損リスクがまとめて解消します。

ただし移動はパス依存の設定（`.claude/`配下の設定など）に影響する可能性があるので、
**移動作業自体は別途指示します。今回はcommitとpushまでで止めてください。**

---

## 5. 報告してほしいこと

- commitの分け方と、各コミットに含めたもの
- `.gitignore`に追加したものがあればその内容
- Dropboxの競合コピーが見つかった場合はその一覧（削除してよいか判断します）
- pushの成否（リモート未設定ならその旨）
