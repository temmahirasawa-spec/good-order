# `/admin/takeout` を `/admin/menu` に統合する

先の修正で「テイクアウト対象にする」トグルが入り、テイクアウト商品も`/admin/menu`から
編集できるようになりました。結果として**同じ商品を2つの画面から編集できる状態**になって
いるため、`/admin/takeout`を廃止して`/admin/menu`に一本化します。

Figma側も対応済みです（`Takeout Management`セクションは削除、メニュー管理にフィルター行を追加）。

---

## 1. フィルター行に「テイクアウト」チップを追加

**これは必須です。** テイクアウト商品は`category_id`が**NULL**なので、どのカテゴリー
チップにも該当せず、「すべて」でしか表示されません。店内メニュー80品以上の中に
5品が埋もれる形になり、実質たどり着けなくなります。

### 配置と見た目（Figma実測）

チップの並び順は **`すべて` → `テイクアウト` → 各カテゴリー…** としてください。
末尾ではなく**2番目**に置くのは理由が2つあります。

- テイクアウトはカテゴリーではなく「提供形態」という別の軸なので、カテゴリー群の
  末尾に混ぜると「ただのカテゴリーの1つ」に見えてしまう
- 2番目ならSP幅（390px）でも横スクロールせずに常に見える位置に収まる（実測で確認済み）

「テイクアウト」チップにのみ、**🛍 Bagアイコン（14×14）をラベルの左**に付けてください
（他の軸のフィルターであることを視覚的に示すためです）。

チップの仕様:
- パディング 左右14・上下8、角丸`radius/full`、要素間6px
- 非選択: 背景`bg/tertiary` / 文字`text/primary`
- 選択中: 背景`surface/ink` / 文字`text/inverse`
- ラベルは`type-jp-body`
- 行の下パディング12px、チップ間8px、横スクロール

## 2. テイクアウトフィルター時は並び替えを有効にする

現在「カテゴリーフィルター適用中は並び替え不可」という制約がありますが、
**テイクアウトで絞ったときだけは並び替えを許可**してください。

理由: カテゴリーフィルターは「全体の一部」なので全体順序に写像できませんが、
**テイクアウトで絞った集合は`/order/takeout`に表示される全商品そのもの**なので、
その中での並び替えは全体順序と矛盾しません。

逆にこれを許可しないと、テイクアウト商品の並び順を**永久に変更できなくなります**
（「すべて」では80品の中に散らばっていて並び替えようがなく、絞り込むと封じられるため）。

実装上、`display_order`をどう振り直すかは判断をお任せします。テイクアウト商品だけで
連番を持つのが自然か、全体の`display_order`の中で相対順序だけ入れ替えるのが自然か、
既存のデータ構造を見て決めてください。**方針だけ一言報告**してもらえれば十分です。

## 3. `/admin/takeout` の廃止

- ナビゲーション（`lib/staffRoles.ts`の`ADMIN_NAV_ITEMS`、`NavContent`の`NAV_ICONS`）から
  「テイクアウト管理」の項目を削除
- ページ自体は削除して構いませんが、**`/admin/menu`へのリダイレクトを置く方が親切**だと
  思います（ブックマークされている可能性があるため）。判断はお任せします
- `app/admin/(protected)/layout.tsx`の`REDESIGNED_PREFIXES`からも該当エントリを削除

**注意**: `/admin/pickup`（テイクアウト受け渡し）は別画面なので、**そのまま残してください**。
削除するのは`/admin/takeout`（テイクアウト商品のCRUD）だけです。
