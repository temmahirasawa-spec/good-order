## 2. 店内注文では受渡番号を非表示にする

`/complete`（ご注文を承りました画面）で、現在は注文種別に関係なく受渡番号を表示していますが、
**店内注文（dine_in）では非表示**にしてください。店内は配膳なので受渡番号を使う場面がありません。

- テイクアウト注文（takeout）ではこれまで通り表示
- 店内注文では、受渡番号の行ごと非表示（空欄やプレースホルダーは残さない）
- 採番自体（`pickup_no` の付与）は今まで通りで構いません。表示の出し分けだけの対応です

---

## 3. `/admin/menu` でテイクアウト商品が保存できない不具合

検証中に見つかった不具合の修正です。

**現象**: `/admin/menu` の編集パネルでカテゴリー選択が `required` になっているため、
`category_id` が NULL のテイクアウト商品を保存しようとすると「選択してください」で弾かれます。
かといってカテゴリーを選ぶと、店内カテゴリーに紐づいてしまいます。結果、テイクアウト商品は
`/admin/takeout` からしか編集できない状態になっています。

**対応方針**: テイクアウト商品（`is_takeout = true`）の場合はカテゴリー選択を必須から外し、
`category_id` を NULL のまま保存できるようにしてください。

- Step3-K で追加した「テイクアウト対象にする」トグルと連動する形が自然だと思います
  （トグルON時はカテゴリー選択を任意にする、など）
- 実装上もっと素直な方法があればそちらで構いません。方針だけ一言報告してもらえれば十分です
- 店内商品のカテゴリー必須バリデーションは、これまで通り維持してください
