## A. TOPページのヘッダーをComponentsのHeader/Close・Header/Openに差し替え

現状、TOPページは既存の `<Header mode="home" />` のままになっています。これを
UTUTUファイルの Components ページにある以下2つのコンポーネントに差し替えてください。

- `Header / Close`（node `176:1509`）
- `Header / Open`（node `338:2267`）

### 構成
`[Header Icon Button（左）] [Logo / Horizontal（中央）]` の2要素、横390px。
（右側に×アイコンのボタンがもう1つありましたが、左右に誤って重複配置されていただけの
ミスだったため、Figma側で削除済みです。削除した直後はオートレイアウトの整列ルールの影響で
左ボタンが中央に寄ってロゴと重なる事故が起きたため、左ボタン・ロゴともに絶対配置に変更し、
左ボタン=x16固定／ロゴ=x141固定（常に中央）で、互いに干渉しない作りにしてあります）

- **Open状態**（ドロワー閉時）: 左ボタン = ハンバーガー（☰ / `Icon=Menu`）
- **Close状態**（ドロワー開時）: 左ボタン = 閉じる（× / `Icon=Close`）

### 実装方針
- 左ボタンのタップで、既存のドロワー（スタッフ呼出/履歴/テイクアウト/店舗情報の導線、
  現行実装のまま流用）の開閉をトグルする
- ドロワーが閉じている間は `Header / Open` を、開いている間は `Header / Close` を出し分ける
  （2つの別コンポーネントではなく、実装上は1つの `Header` コンポーネントに
  `isDrawerOpen` propを渡して左アイコンだけ出し分ける形で構いません。Figma側が
  2コンポーネントに分かれているのは単に状態ごとのデザイン確認用です）
- ロゴ・全体のレイアウト・ドロワーの中身は現行のまま変更不要です

## B. 商品詳細ページ（/order/item/[id]）の実装

Figma参照: `Product Detail`（390×2046, node `80:894`）

### ページ構成（上から順）

1. **KV**（390×260）: 商品のメイン画像（`item.image`）をフル幅で表示。
   左上に **Header Icon Button**（`Icon=Menu`、44×44、写真に浮かせて配置）を重ねる。
   タップ時の挙動はTOPページのヘッダー左ボタンと同じドロワー開閉（Aで実装したものを共有）
2. **Intro**（390×177）:
   - `CategoryTag`（`item.subcategory` を既存LABELS辞書でJPラベル化）
   - `Title`: `item.name`
   - `Body`: `item.description`
3. **Sub Image**（300×300、中央寄せ）: 補助画像。データ有無は要確認（下記参照）
4. **Video / 9:16**（342×608、中央寄せ）: 縦動画。データ有無は要確認（下記参照）
5. **Recommended**（390×541）:
   - 見出し: `RECOMMENDED` / `関連のおすすめ`
   - `Recommend Carousel`（`RecommendCard` 300×348 を横スクロール、2枚目はみ出し表示）
   - データ: 同一 `subcategory` の他アイテムから、自分自身を除外して `display_order` 順に
     最大6件取得（新規関数 `computeRelatedItems(items, currentItem, limit=6)` を追加する形で
     問題ないか判断は任せます）
6. **Bottom Detail Bar**（390×84、画面下部に固定/sticky）:
   - `Back Button`: タップで前の画面に戻る（`router.back()`。仮に遷移元が無い場合の
     フォールバックは `/order` へ）
   - `Add to Cart Button`（アイコン+「カートに入れる」）: タップ1回でカートに該当商品を
     1点追加（既存のzustandカートstateにそのまま反映。数量選択UIはこの画面には無く、
     複数個入れたい場合は連打 or カート画面側で調整する仕様のままでOKです）

### データ取得
- 対象アイテムは `id`（動的ルートパラメータ）で既存の全件データ（`useMenuDataStore` 等）
  から検索する形でOKです。個別フェッチが必要かはStep3-Aで確認済みの実装方針に準じてください
- ルート自体はStep3-Aの時点でプレースホルダーとして存在しているはずなので、
  新規ルート追加ではなく中身の実装差し替えになります

### 確認したいこと

1. **Sub Image・Video（9:16）の2フィールド**は `menu_items` テーブルに既に存在しますか？
   存在しない場合、無理に新しいカラムを増やさず、**「データがあれば表示、無ければ
   そのセクションごと非表示」**という実装で進めてもらって大丈夫です
   （全アイテムに用意するのは現実的ではないため）
