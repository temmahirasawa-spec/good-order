## これは何のため

管理画面は「当日の運用」と「設定」の 2 つに分かれています。左のサイドバー（スマホは左上の ≡）の並びがそのまま章の並びです。

## サイドバーの並び

上の 4 つは当日の運用（第2部）、区切り線の下は設定です。

1. 厨房
2. レジ
3. テイクアウト
4. 印刷状況
5. メニュー（開くと「メニュー管理」「カテゴリ管理」「セットドリンク」）
6. テーブル／二次元コード
7. 表示設定
8. 税の設定
9. 店舗情報
10. ダッシュボード（いちばん下）

設定の画面（5〜10）は**マネージャーだけ**が開けます。例外は「印刷状況」の中の「伝票の枚数」で、厨房・カウンターも変えられます。

## ログイン

- 管理画面の URL に `/admin/login` を付けて開きます
- メールアドレスとパスワードで「**ログイン**」
- 着地する画面は役割で変わります（第2部 6）

エラーの読み方:

- 「メールアドレスまたはパスワードが正しくありません」→ 入力ミス。大文字小文字も確認
- 「このアカウントには権限（role）が設定されていない」→ アカウントに役割が付いていません。作った人に連絡
- 「ネットワークエラー」→ Wi-Fi を確認

## アカウントの作り方

アカウントの追加・削除・パスワードの再設定は**管理画面からはできません**。データベースの管理ツール（Supabase の Authentication）でメールアドレスとパスワードを作り、そのアカウントに役割（manager / kitchen / register / counter のどれか）を付けます。開発側で行うので、必要なときは依頼してください。

> [YORKYS] YORKYS BRUNCH ではログイン画面に「YORKYS BRUNCH / Admin Console」と出ます。製品版では店名に置き換わります。
