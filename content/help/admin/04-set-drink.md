## これは何のため

[店ごと] 「食事と一緒のドリンクは 200 円引き」のような割引を、お客様のカートで自動的に引きます。スタッフがレジで計算する必要はありません。

## 設定の項目

1. **セットドリンク割引を使う**（ON/OFF）
2. **1杯あたりの割引額**（円・税抜き）: 初期値 200。ドリンクの単価より高い額は引きません（100 円のドリンクなら 100 円引き）
3. **テイクアウトの注文にも適用する**: OFF なら店内だけ
4. **どれがフードで、どれがドリンクか**: カテゴリの「区分」で決まります。ここでは確認だけ。変えるときは「カテゴリ管理」へ

「**保存する**」で反映。

## 計算の決まり（そのまま覚えてください）

- 割引される杯数 = フードの点数とドリンクの杯数の**少ないほう**
- **安いドリンクから**順に、1 杯につき「設定額」か「その杯の単価」の安いほう
- **同じ卓の未会計の注文ぜんぶ**で数えます。先に食事を頼んで、あとから別のスマホでドリンクを頼んでも割引されます
- 会計すると数え直しが始まります（次のお客様は最初から）
- 割引はカート・完了画面・注文履歴・レジに「セットドリンク割引 −¥200」と出ます。0 円のときは行ごと出ません

> [YORKYS] YORKYS BRUNCH ではアルコールも「ドリンク」区分なので割引の対象です。対象から外したい場合は区分の設計を変える必要があります（開発側に相談）。
