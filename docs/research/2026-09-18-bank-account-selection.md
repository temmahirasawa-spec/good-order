# UTUTU の法人口座をどこで作るか — 洋輔さん判断用

_2026-09-18 作成（天真の依頼）。前提: 株式会社 UTUTU は 2026-09-07 設立、法人番号は公表サイトに掲載済み。当面の用途は Stripe（決済代行）からの入金受け取り・経費支払い・将来の創業融資。**今回はスピードを重視**。_

## 1. 結論（先に）

| 順位 | 銀行 | 推奨度 | 一言 |

| 1 | **三井住友銀行 Trunk** | ◎ | メガバンクの名前・スピード・手数料の三拍子。Stripe の入金先として実績あり。融資は別枠だが、今の UTUTU に融資の予定は無い |
| 2 | **GMOあおぞらネット銀行** | ○ | 最速・最安（設立1年未満は他行宛が月20回無料）。API と会計連携に強い。銀行名の信用はメガバンクに劣る |
| 3 | **みずほ UPSIDER BANK**（2026-06 開始） | ○（様子見） | メガバンク名＋他行宛100円＋最短即日。まだ始まって 3 か月で情報が少ない |

## 2. 主要な銀行の現状（2026 年 9 月）

### 三井住友銀行 Trunk（トランク）
- 2024 年開始の「オンライン完結型」法人口座。**新設法人を主なターゲット**にしている
- 申し込み: スマホで最短 20 分。**必要書類は本人確認＋「事業内容がわかる書類」1 点**（登記事項証明書・定款・事業計画などのどれか）。登記事項証明書と印鑑証明を郵送する従来型ではない
- 開設: **最短即日〜翌営業日**。インターネットバンキングの利用開始は 1 週間程度
- 手数料: 月額 0 円、SMBC 宛 0 円、**他行宛 100 円**（2025-05 以降）
- できないこと: 通帳なし、窓口なし、現金の入出金は限定的（ATM 可、窓口は不可）、**融資はこの口座では扱わない**（必要になったら通常口座への切り替えや別途相談）
- 会計ソフト連携: freee 等と API 連携
- 審査はある。「必ず通る」わけではないが、税理士の比較記事でも「新設法人にも比較的積極的」と評価
- 出典: [SMBC Trunk](https://www.smbc.co.jp/hojin/kouza/)、[Trunk が合理的な 3 つの理由（SMBC）](https://www.smbc.co.jp/hojin/kouza/column/banking/trunk-corporate-account.html)、[創業手帳の解説](https://sogyotecho.jp/smbc-trunk/)

### GMOあおぞらネット銀行
- ネット銀行の中で新設法人の開設実績が最も多い部類。IT・Web 系のスタートアップに人気
- 申し込み: オンライン完結。**代表者と取引責任者が同じ人で、セルフィー動画かマイナンバーカードで本人確認すれば最短即日**
- 手数料: 月額 0 円、**他行宛 130 円**（条件で最安 100 円台）。**設立 1 年未満は他行宛が毎月 20 回無料**（設立 1 年を迎える月の翌月末まで）
- 法人カード: 還元率 1%。デビット専用サブカードあり
- **API が充実**（残高・明細・振込を自動化）。freee・マネーフォワード連携も強い
- 融資: 自行のビジネスローンのみ。保証協会付き融資や公庫の窓口にはならない（公庫の返済口座には指定できる）
- 注意: バーチャルオフィスは郵便物の受け取り確認が必須。受け取れないと口座が制限される
- 出典: [GMOあおぞら 法人口座](https://gmo-aozora.com/promotion/lp/business_account/)、[API 連携](https://gmo-aozora.com/business/api-cooperation/)、[税理士の比較](https://www.century-partners.jp/17792596868161)

### みずほ銀行 UPSIDER BANK by MIZUHO（2026-06-30 開始）
- みずほと UPSIDER（法人カードの会社）の共同サービス。**みずほに口座を持たない新設・成長期の会社向けのオンライン専用プラン**
- 口座・ネットバンキング・法人カード・資金調達が一体。UPSIDER の AI 与信でカード限度額を上げられる
- 手数料: 契約料・月額 0 円、**他行宛 100 円**。開設は最短即日とされる
- まだ始まって 3 か月で、審査の実態や落とし穴の情報が少ない。「メガバンク名で 100 円」という点では Trunk の直接の対抗馬
- 出典: [Impress Watch](https://www.watch.impress.co.jp/docs/news/2121285.html)、[Business Insider](https://www.businessinsider.jp/article/2607-mizuho-upsider-bank-launch/)、[みずほ公式](https://www.mizuhobank.co.jp/corporate/account/index.html)

### ドコモSMTBネット銀行（旧 住信SBIネット銀行）
- 2025-10 に NTT ドコモの連結子会社となり、三井住友信託銀行との共同経営に。**2026-08-03 に社名変更**。法人向けは「NEOBANK BIZ」の名前で継続
- 金融機関コード・支店・口座番号・手数料は変わっていない（他行宛 145 円、優遇で 130 円）。口座開設月と翌月は他行宛が月 10 回無料
- 開設スピードは「標準的」（Trunk や GMO ほど速くない）
- 天真の懸念（新しすぎる・ドコモのイメージ）について: 銀行としての実体は 2007 年からの住信SBI で、資本が変わっただけ。ただし今後は d ポイント連携など個人向けのドコモ色が強まる方向。**法人としてあえて今これを選ぶ積極的な理由は無い**
- 出典: [ドコモ プレスリリース](https://www.docomo.ne.jp/info/news_release/2025/12/19_00.html)、[社名変更の案内](https://www.netbk.co.jp/contents/lp/ci/)

### PayPay銀行
- 開設は最短 3 日〜10 日。設立半年以内は事業計画書・資金計画書を求められることがある
- 他行宛 145 円、PayPay銀行宛 0 円。保証協会付き融資や制度融資に対応しているのはネット銀行では珍しい
- **Stripe の入金先候補に出ないという 2023 年の調査報告**があり、今回の用途には向かない
- 出典: [PayPay銀行 FAQ](https://faq.paypay-bank.co.jp/faq/show/97?site_domain=business)、[Wise の解説](https://wise.com/jp/blog/open-business-account-with-paypay-bank)

### 三菱UFJ（通常の法人口座）
- Web 申し込みはできるが、**審査に 1〜1.5 か月**。新設法人は事業実態の資料が多め
- 銀行名の信用は最上位だが、今回のスピード重視とは合わない。取引先や融資の都合で必要になった時点で 2 口座目として作ればよい
- 出典: [三菱UFJ 法人口座開設](https://www.bk.mufg.jp/houjin/kouza_kaisetu.html)

### 地方銀行・信用金庫
- 開設は来店必須で 2〜4 週間。手数料は高め（他行宛 440〜770 円）
- 強みは**創業融資**。日本政策金融公庫の「新規開業・スタートアップ支援資金」と、信用保証協会付きの制度融資は、地元の信金・地銀の担当者がついて進めるのが一般的。UTUTU が融資を本気で使うなら、会社所在地の信金で 2 口座目を作り、そこを融資用にする
- 出典: [マネーフォワード 法人口座比較](https://biz.moneyforward.com/establish/basic/53216/)、[創業手帳 公庫の解説](https://sogyotecho.jp/shinsougyouyushi-haishi/)

## 3. Stripe の入金先として使えるか（今回の最重要条件）

- Stripe（Connect 含む）の日本の入金先は約 260 行。2023-08 の調査で **三井住友・三菱UFJ・みずほ・住信SBI（現ドコモSMTB）・あおぞら銀行は候補に出る**。**楽天銀行・ゆうちょ銀行は出ない**（PayPay銀行も出ない可能性）
- GMOあおぞらネット銀行は「あおぞら銀行」と別の銀行で、上の調査では名前が挙がっていない。実際には多くのスタートアップが Stripe の入金先にしているが、**申し込み前に Stripe のダッシュボードで銀行名を検索して候補に出るか確認する**のが確実（アカウント作成後、入金設定の画面で検索できる）
- 出典: [Stripe Connect 対応銀行の調査（ncaq）](https://www.ncaq.net/2023/08/02/00/07/50/)、[Stripe: 銀行が利用できません](https://support.stripe.com/questions/why-isnt-my-bank-available)

## 4. 一般にあまり知られていない選択肢・考え方

1. **「ネット銀行をメイン、メガバンクをサブ」が 2026 年の定石**だが、Trunk の登場で「メガバンク名のままネット銀行並みの手数料」が成立した。UTUTU の規模なら Trunk 1 口座で両方を兼ねられる
2. **UPSIDER BANK by MIZUHO** は法人カードの与信が最初から付いてくる。経費をカードで回す設計にするなら、Trunk より合う可能性がある。ただし新しすぎるので、半年後の評判を見てから 2 口座目に検討
3. **GMOあおぞらの「設立 1 年未満・他行宛 20 回無料」**は、店舗への支払いや外注費の振込が月に数十件になるまでは実質ゼロコスト。将来 GOOD ORDER が店ごとに売上を分配する（プラットフォーム）段階になると、**API で振込を自動化できる**のは GMOあおぞらだけ。その時点で 2 口座目として作る価値がある
4. **2 口座を最初から持つ**のは手間に見えるが、月額はどちらもゼロ。「審査落ちの保険」と「役割分担（Trunk＝対外・入金、GMO＝自動振込）」の両方で効く

## 5. 申し込みに向けて今日できること

- Trunk: 代表者の本人確認書類（免許証かマイナンバーカード）＋「事業内容がわかる書類」1 点。**定款か登記事項証明書の PDF があれば足りる**。スマホで 20 分
- GMOあおぞら: 代表者本人がスマホで申し込み（セルフィー動画かマイナンバーカード）。事業内容確認書類（定款・登記事項証明書・会社概要のどれか）
- どちらも法人の印鑑証明は不要。会社の Web サイトがあると審査が通りやすいので、Stripe 申請と同じく最低限の会社ページを先に用意する
- 開設後: Stripe のダッシュボードで入金先に登録できるか確認 → できれば決定

## 6. 洋輔さんに決めてほしいこと

1. **メインを Trunk でよいか**（融資を近いうちに使う予定があるなら、信金との 2 口座体制を最初から組む）
2. **GMOあおぞらを保険として同時に申し込むか**
3. 申し込みの名義人: 代表者本人が申し込む必要がある（Trunk・GMO とも代表者の本人確認）。代表者は洋輔さんか天真か、で作業する人が決まる
