## 2. 今日は触らない操作

| 操作 | 触るとどうなるか |
|---|---|
| 席設定（テーブル/二次元コード画面の保存・削除） | 卓が消えて、**その卓の紙が全部読めなくなる**。カードの「削除」は確認なしで1タップで消える |
| カテゴリの削除 | そのカテゴリの商品が**全部消える**（注文実績の無いカテゴリは止まらない） |
| 営業中の価格変更 | 既にカートに入っている分は古い価格で通る。レジと食い違う |
| 表示設定 ＞ 使う機能 | 厨房画面・スタッフ呼び出しの ON/OFF。今日は変えない |
| メニュー ＞ セットドリンク | 変えるなら**開店前に**。営業中に変えると前後で金額が変わる |
| 商品の「非表示」 | その商品をカートに入れているお客様が注文できなくなる。**売り切れは「売り切れ」チップを使う**（非表示にしない） |
| オプション（HOT/ICED 等）の非表示 | 同上。そのオプションを選んでいるお客様は注文できなくなり、画面の案内どおりにしても直らない |

## 3. 営業中に困ったとき

### 伝票が出ない
1. 「印刷状況」を開く。上のカードが「停止」なら電源・Wi-Fi
2. 「出ていない伝票」に赤い **「失敗」** があれば **「刷り直す」** を押す（紙・カバーを直してから）
3. それでも出ない → **レジ画面で卓を選ぶと明細が見える**。それを厨房に口頭で伝える
4. 天真に連絡

### 注文を止めたい（厨房が回らない・プリンタが直らない）
- 画面にスイッチは無い。**天真に連絡**すると DB 側で止められる（お客様には「受付を一時停止しています」と出る）
- 応急処置: 商品を「売り切れ」にすると、その商品は注文できなくなる

### 二重注文・押し間違いの会計
- 画面から取り消す手段は無い。**注文ID（レジ画面の「内部ID」6桁）か卓名と時刻を天真に連絡**。DB 側で消す・戻す
- 会計を押し間違えると、その卓のお客様のスマホは15秒以内に「THANK YOU」になる。**もう一度二次元コードを読んでもらえば注文を続けられる**

### 画面が固まった・古いまま
- レジ画面は通信が切れても何も出ない。**1時間に1回は画面を再読み込み**する
- ログイン画面に戻ったらログインし直して「レジ」へ

### お客様が「注文できない」と言う
- 「通信エラー」の表示 → もう一度押してもらう。繰り返すならスタッフが口頭で受ける
- 「お取り扱いが終わった商品」の表示 → カートの赤い行を削除してもらう。赤い行が無いのに出るときは、HOT/ICED などのオプションが原因。**カートを空にして入れ直してもらう**
- 「THANK YOU」の画面 → 二次元コードをもう一度読んでもらう
