4. 決めてほしいこと

2. 写真なしの文字メニュー
  1. 器: A 行リスト推奨／ B カード＋色タイル／ C 分けて出す
  2. 自動判定: 「写真が1枚も無ければ文字リスト」でよいか
  3. 混在のとき: 写真ありも行にする（サムネ付き）でよいか
  4. 範囲: ホームとカテゴリー一覧ページの両方を行にするか、ホームだけか
  5. 写真なしの詳細: カテゴリー色の帯から始めてよいか
3. モスグリーンとブランドカラー
  1. 色: M1推奨／ M2／ M3／ M4／ M5
  2. 切替の時期: リニューアルと同時に本番を緑にする／ まずプレビューで見る
  3. 設定 UI: プリセット＋カスタム HEX推奨／ プリセットだけ／ カスタムだけ
  4. 読みにくい色: 保存できない推奨／ 警告だけ
  5. 白文字への切替: 色から自動判定推奨／ 店舗が白か黒かを選ぶ
