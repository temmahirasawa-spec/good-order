# 報告・提案の 1枚 HTML（report-artifact）

クライアントや上長など「エンジニアではない相手」に、やったこと・決めたこと・次にやることを
**1つの HTML ファイル**で渡すための作法。

## いつ使うか

- 「HTML にして」「資料にして」「URL で共有できるように」「〇〇さんに見せたい」と言われたとき
- 要望への回答（要望ごとに「原因 → 途中経過 → 結論」）、進捗報告、3案の提示、変更前後の比較

## 作る前に決めること（3行で書いてから作る）

1. **相手と、この1枚の仕事**: 誰が読むか、読んだあとに何をしてほしいか（例: 3案から1つ選ぶ／変更内容を把握する）
2. **色**: その題材の色を使う。案件なら**その案件・クライアントのブランド色**を accent に（自分の好みの色を持ち込まない）。
   accent 1色 ＋ その薄い地 ＋ 墨 ＋ 副文字色 ＋ 罫線 ＋ ページの地、の 4〜6 色を HEX で決める
3. **書体**: 題材が使っている書体を使う（無ければ、英語の見出し用に Barlow のような幾何学的なサンセリフ、日本語本文用に Noto Sans JP）。英語の見出し用 1つ、日本語本文用 1つ。Google Fonts から読む

## 構成（この順番。要らない段は抜く）

| 段 | 中身 |
|---|---|
| ヘッダー | 左: 小さな eyebrow（案件名／プロダクト名）→ 英語の大見出し → 日本語の一言。右: 日付・件数・作成者。下に 2px の墨の罫線 |
| サマリー | 要望や論点ごとに 1枚ずつ。`01 / LABEL` のような番号＋英語ラベル、日本語の見出し、1〜2文の結論 |
| 各セクション | 見出しは **eyebrow（例: ご要望 1）→ 英語のラベル → 日本語の見出し**。本文は左に文章、右に画面。文章は「原因 → 途中経過 → **結論（枠で強調）** → 箇条書きの補足」 |
| 画面 | 変更前／変更後／Figma／管理画面 を **タグ付きのカード**で並べる（BEFORE は旧ブランド色、AFTER・FIGMA・ADMIN は accent）。縦長のスマホ画面はカードの中でスクロール（`max-height` ＋ `overflow-y:auto`） |
| 色・部品の説明 | 色を変えた話なら、色チップ（primary / pressed / deep / subtle / text on accent / old）を並べる |
| これから | 順番をチップで `A → B → C`。表で「項目 ／ 状態」 |
| フッター | 作成者、参照した仕様書のパス |

## 書き方

- 日本語で。専門用語は直後に「＝何が起きるか」を添える（例: 「マイグレーション＝データベースに列を足す」）
- 結論を先に。1文 20〜40 字。1つの段落に 1つの話
- 「私（AI）が決めたこと」は必ず「いつでも覆せる」と添えて、決定と区別する
- 数字は本文に混ぜず、表かチップに出す
- 画像には必ず 1行の説明（何の画面か、どこを見るか）
- タイトル（`<title>`）は資料の名前。2〜4語の名詞（例: 「〇〇 画面アップデート」）。「〜について」「〜の資料」を付けない

## 作り方（技術）

- **1ファイルで完結**させる。画像は PNG を base64 の `data:` URI で埋め込む（Python で `base64.b64encode`）。16MB 以内
- スクリーンショットは **SP 390px** を基本に、必要なら PC 1400px。スマホ画面は幅 390 で撮って 2倍で保存
- CSS はテンプレート（`template.html`）をそのまま使い、`:root` の色と書体だけ差し替える
- ダーク表示にも対応する（テンプレートに入っている。色は必ず `:root` の変数経由で使い、直書きしない）
- スマホ幅（760px 以下）で 1列に落ちること（テンプレートに入っている）
- Claude Code なら Artifact ツールで公開して URL を渡す（favicon は絵文字 1つ、説明文は 1文）。
  Artifact が無い環境なら、そのままファイルで渡す（ファイル 1つで開ける）
- リポジトリに残す場合は `docs/share/YYYY-MM-DD-題材.html`

## やらないこと

- Lorem ipsum、ダミーの数字（実データが無ければ「例」と明記）
- 絵文字の見出し、全部センター揃え、全部に角丸と影、紫〜青のグラデーション、Inter の見出し
- 色や書体を「いつもの」にする（題材の色・書体を使う）
- 長い画面の画像を縮小してつぶす（カード内スクロールにする）
