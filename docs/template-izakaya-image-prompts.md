# 居酒屋テンプレート用 メニュー画像 生成プロンプト集

モックアップに出ている商品ぶんの画像を ChatGPT で生成するためのプロンプト。
**「共通スタイル」を毎回いちばん先に貼り、そのあとに「主題」だけを差し替える**運用にしている。
共通スタイルを省くと、光の向き・色温度・器・背景が1枚ごとに変わり、
一覧に並べた瞬間にバラバラに見える。ここが品質を決める。

---

## 生成ルール（先に読む）

### アスペクト比は 1:1、四辺に20%の余白

1枚の画像を4つのスロットで使い回すため、**正方形で生成し、主題を中央に置き、
上下左右それぞれ20%には主題を置かない**。こうすると全スロットでセンタークロップだけで収まり、
はめ込み時に構図をいじらなくて済む。

| 使う場所 | 表示サイズ | 1:1からの切り出し | 上下から捨てる量 |
|---|---|---|---|
| 一覧行のサムネ | 64×64 | 1:1（そのまま） | 0% |
| ベストセラー / おすすめカード | 140×105 | 4:3 | 各12.5% |
| 2列グリッドカード | 171×114 | 3:2 | 各16.7% |
| 商品詳細のKV | 390×260 | 3:2 | 各16.7% |
| 商品詳細のサブ画像 | 300×300 | 1:1（そのまま） | 0% |

→ 最大 16.7% 切られるので、**余白20%**が安全ライン。

ヒーロー帯（390×160）だけは 16:9 で別に生成する。

### 1商品あたり2枚あると理想

- **引き**（皿と卓上の小物が入る）… 一覧・カード用
- **寄り**（料理のディテール）… 商品詳細のサブ画像用

まずは「引き」だけ全商品ぶん作り、詳細ページを作り込む商品だけ「寄り」を足す運用で十分。

### 出力後

`assets/images/menu/izakaya/<スラッグ>.jpg` に置いてパスを教えてください。
Figmaのモックアップへの流し込みはこちらで行います（現在は暖色のグラデーションが入っています）。

## 共通スタイル（毎回この塊を先頭に貼る）

```
日本の大衆居酒屋の卓上を撮った料理写真を1枚作ってください。

【撮り方】
・斜め45度上から見下ろした角度。真俯瞰にはしない。
・光は右手前からの暖色の白熱灯。柔らかい影が左奥に落ちる。色温度は低め（3000K前後）。
・背景は使い込まれた濃い茶色の木のカウンター。奥は暗く落ちて大きくボケている（f/2.8相当）。

【色と質感】
・茶・飴色・朱を基調にする。青白い光やパステルカラーは使わない。
・湯気、焼き目、脂のつや、炭の粉など「たった今できた」情報を必ず入れる。

【卓上の小物】
・割り箸（箸袋つき）／和柄の小皿／生成りの布ナプキン／和紙のコースター／
  七味唐辛子の小瓶／おしぼり のうち2〜3点を、主題の周囲に自然に散らす。
・器は白い洋皿ではなく、黒い角皿・飴釉の和食器・竹のざるなど和のもの。

【狙う雰囲気】
・洗練された高級店ではなく、賑やかで温かみのある大衆店。少し雑然としていてよい。

【構図】
・正方形（1:1）。主題は画面中央。上下左右それぞれ20%の帯には主題を置かない。

【含めないもの】
・文字、ロゴ、メニュー表、値札
・人物の顔や手
・真っ白でモダンな皿、強いHDR、青いライト、真俯瞰の構図
```

## 商品別の主題

### 焼鳥

**1. もも貴族焼（塩）** `momo-shio`
```
【主題】太めの竹串に刺した鶏もも肉の塩焼きが2本。黒い角皿に少し斜めに並べる。
皮目にしっかりとした焦げ目がつき、粗塩の粒が光っている。肉の断面から肉汁がにじむ。
脇に山椒を入れた小皿と、くし切りのレモンをひと切れ。
```

**2. もも貴族焼（タレ）** `momo-tare`
```
【主題】太めの竹串に刺した鶏もも肉のタレ焼きが2本。黒い角皿に並べる。
濃い茶色のタレをまとって強い照りがあり、タレがとろりと皿に少し垂れている。
串の先まで艶が乗っている。仕上げに白ごまをひとつまみ。
```

**3. むね貴族焼（塩）** `mune-shio`
```
【主題】鶏むね肉の塩焼きが2本。ももより淡い焼き色で、断面がしっとり白い。
黒い角皿に並べ、脇に小さなわさびの玉を添える。表面に粗塩と黒こしょう。
```

**4. つくね（月見）** `tsukune-tsukimi`
```
【主題】粗挽きの鶏つくねが串に2本。照りのあるタレをまとっている。
手前の小鉢に生卵の黄身がひとつ入っていて、片方の串の先を黄身に軽く浸したところ。
黄身にとろりとした光。皿は黒、小鉢は飴釉。
```

**5. ぼんじり** `bonjiri`
```
【主題】鶏の尾肉（ぼんじり）が串に4〜5個刺さったものが2本。
小ぶりで丸く、脂がのってぷっくり張っている。表面で脂がはぜて照りが出ている。
軽く焦げた部分と粗塩。黒い角皿。
```

**6. ちからこぶ** `chikarakobu`
```
【主題】鶏の手羽元（腕の部分）を串打ちした大ぶりの一本が2本。
骨がのぞき、皮がぱりっと焼けて縮んでいる。表面に粗塩と少しの焦げ。
食べ応えが伝わるよう、他の串より一回り大きく見える構図。黒い角皿。
```

### ヒーロー帯（1枚だけ 16:9）

**16. ヒーロー** `hero`
```
【主題】居酒屋の卓上をやや引きで撮った1枚。
焼鳥の盛り合わせ、生ビール、小鉢がいくつか並び、焼鳥から湯気が立っている。
奥のほうに赤提灯の灯りが丸い玉ボケになって浮かんでいる。
人物の顔は入れない（後ろ姿のシルエットが遠くにボケている程度は可）。

【構図の指定を上書き】
・正方形ではなく 16:9 の横長で生成する。
・画面の左半分に主題を寄せ、右側は暗く落として余白にする
  （右側に白い明朝体のコピーを重ねるため）。
```

## 生成後のチェック

並べたときに破綻していないかを、この順で見る。

1. **サムネ64pxに縮小して見分けがつくか**。ここで潰れる写真は一覧で機能しない
2. **背景の木の色が全画像で揃っているか**。1枚だけ明るいと目立って浮く
3. **光の向きが揃っているか**（右手前から）。影の向きが逆の画像が混ざると気持ち悪い
4. **和の小物が入っているか**。料理単体の切り抜きだと居酒屋感が出ない
5. **上下を16.7%切っても主題が欠けないか**
