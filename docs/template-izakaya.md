# 業態テンプレート検証：居酒屋

販売用テンプレートの1本目。**機能は既存の YORKYS BRUNCH テンプレートから一切変えず、
デザインだけを差し替える**という制約で設計している。

題材に鳥貴族を借りているのは「誰もが知っていてイメージしやすい居酒屋」だからで、
鳥貴族固有の仕様（全品390円均一など）はテンプレートの前提にしていない。

- Figma: UTUTU / ページ「居酒屋」（`node-id=913-37114`）
- 対象画面: TOP、商品詳細
- 更新: 2026-07-30

---

## 1. なぜ居酒屋か

現行デザイン（YORKYS＝カフェ）は 200×200 の大きな写真を横カルーセルで見せる構成で、
**1画面に約1.9品しか入らない**。「1人あたり2〜3品・写真で選ぶ」カフェには最適だが、
居酒屋・イタリアン・ラーメン屋のように

- 総メニュー数が100品規模
- 1卓で10〜20品を、3〜4回のラウンドに分けて注文する
- 焼鳥の串のように**写真では見分けがつかない**商品が並ぶ

業態では機能しない。テンプレートを切り替えるだけで一覧性の高い構成になるか、を検証した。

## 2. 事前リサーチ

### 2-1. 鳥貴族の実際のオーダー体験

| 項目 | 内容 |
|---|---|
| 注文方式 | 2017〜18年に**テーブル据置のタッチパネル**を全店導入。店員は注文を取りに来ない |
| カテゴリ | 期間限定 / 焼鳥 / 逸品料理 / スピードメニュー / ご飯もの・デザート / ドリンク（約50種）/ トリキ晩餐会 / テイクアウト |
| 商品の単位 | 焼鳥は**2本で一皿**。鶏以外（もちもちチーズ焼、牛串焼）もある |
| 注文の実態 | 1回で終わらず3〜4ラウンド続く。釜飯は時間がかかるため「3回目に頼んで4回目を食べ終わる頃に届く」といった運用知が客側に蓄積している |
| ブランドカラー | **温かみのある赤**（愛・情熱・リーダーシップ）。社名変更にともなうロゴ刷新でも、中核ブランド「焼鳥屋 鳥貴族」の赤を継承 |
| 価格 | 全品390円均一（2025年5月〜）。ただし2026年4月から静岡の一部店舗でバラ価格をテスト中 |
| 副作用 | タッチパネル導入でピークタイムに厨房へオーダーが溜まり、「待たされる」印象が出たとの指摘がある |

> **均一価格はテンプレートに反映していない。** 業態共通の仕様ではなく、鳥貴族固有の事情だから。
> 価格は各行に常時表示する（＝既存テンプレートと同じ挙動）。
> なお `IZ / Menu Row` と `IZ / Menu Card S` には「価格を表示」のスイッチを持たせてあるので、
> 均一価格の店に当てたくなったときはOFFにするだけで対応できる。

### 2-2. 一般的な居酒屋モバイルオーダーのUI

最も参考になったのは、実導入店の画面を業態別に分析した
[ダイニー「イケてるモバイルオーダー画面10選」](https://dinii.jp/column_20250213/)。

- **写真サイズの使い分けで注目度を設計する**（八百屋とごはん / 焼肉たむら）。全部を大きくしない
- **ディナーは黒基調で高級感、ランチは暖色**（焼肉たむら）＝時間帯で世界観を振る
- **トップ最上段に「今いちばん出したいもの」**を置くと出数が動く
- **1色に絞った強い統一色**（マシマシらーめん＝赤）が業態の記号として効く

居酒屋特有の必須機能（[Bizcan](https://bizcan.jp/column/mobileorder-izakaya/) /
[smasel](https://smasel.com/media/izakaya-mobile-order/)）：
飲み放題の残り時間・ラストオーダー通知、複数人が別端末から同時注文、割り勘、多言語、
タレ／塩のような**オプション選択**。

### 2-3. 結論：居酒屋モバイルオーダーの「正解パターン」

| # | 原則 | 根拠 |
|---|---|---|
| 1 | **一覧性が最優先**。1画面6〜8品 | 100品規模を横スワイプでは探せない |
| 2 | **写真は主役から「識別の手がかり」へ** | 焼鳥の串は写真では見分けがつかない。差は商品名にある |
| 3 | **セクションごとに写真サイズを変える** | 焼鳥は行、逸品料理はグリッド。全部同じ型にしない |
| 4 | **縦スクロール＋sticky カテゴリ帯** | 横カルーセルは「そのカテゴリに何品あるか」が分からない |
| 5 | **ラウンド注文前提**。＋1タップで即カート、点数と合計は常時表示 | 3〜4回追加注文が走る |
| 6 | **墨の額縁＋朱の差し色**。chrome を黒、一覧は明るく保つ | 暗い店内で全面白は眩しく、全面黒は一覧の可読性が落ちる |
| 7 | **見出しは明朝、本文はゴシック** | 和の記号は見出し一点に集約すれば可読性を犠牲にしない |

## 3. カラー設計

既存トークン設計書の原則「Accent set is the only brand-swappable group」に従い、
**アクセント4値の差し替えだけ**でテーマを成立させた。

| トークン | カフェ (YORKYS) | 居酒屋 | 検証 |
|---|---|---|---|
| `accent/primary` | #FAC03D | **#C4302A** | 白文字 5.52:1 ✅ AA |
| `accent/pressed` | #E5A817 | **#A32620** | — |
| `accent/deep` | #996B00 | **#8C1F1A** | 白地の赤文字 9.03:1 ✅ AAA |
| `accent/subtle` | #FFFCF7 | **#FCF2F0** | 上の黒文字 15.83:1 ✅ |
| `accent/on-ink` **(新規)** | #FAC03D | **#EF6A5A** | 墨地 5.70:1 ✅ AA |
| `bg/warm` | #FCF7EE | **#F7F2EA** | 生成りのページ地 |

`#C4302A` を墨（#1A1A1A）の上に置くと **3.15:1** でAAに届かない。
墨を額縁として使うテンプレートでは、墨専用の明るいアクセントが必ず必要になる。

| 追加トークン | 用途 |
|---|---|
| `accent/on-ink` | 墨面の上のアクセント（タブの下線、ヘッダーの印） |
| `surface/ink-soft` (#2B2523) | 墨面の一段明るい面（浮きボタン） |
| `border/on-ink` (white 16%) | 墨面の上のヘアライン |

### 実装方式：Variable Mode = テンプレート

既存ファイルの Color コレクションは既に `YORKYS` / `Demo (Green)` の2モード構成だったので、
**3つ目のモード `Izakaya (鳥貴族)` を追加**した。
「管理画面でテンプレートを切り替える」＝「このモードを切り替える」に1:1で対応する。
`app/design-tokens.css` にも同じ値をコメントで記載済み。

`text` / `border` / `bg` / `tag` / `status` / `spacing` / `radius` / `size` は**一切変更していない**。

### タイポグラフィ

見出し専用に明朝を3スタイル追加（Shippori Mincho B1）。**本文は Noto Sans JP のまま**。

| スタイル | フォント | サイズ / 行間 / 字間 | 用途 |
|---|---|---|---|
| `JP/Mincho/Display` | Shippori Mincho B1 ExtraBold | 26 / 130% / 2% | ヒーローのコピー・商品名 |
| `JP/Mincho/Heading` | Shippori Mincho B1 Bold | 19 / 140% / 2% | 店名・セクション見出し |
| `JP/Mincho/Label` | Shippori Mincho B1 Medium | 12 / 150% / 6% | 補助 |

## 5. 画面（Figma: `02 SP / 居酒屋`）

### TOP

```
[sticky] IZ / Order Header      56  焼鳥屋 鳥貴族 / ☰
[sticky] IZ / Tab Nav           44  おすすめ・焼鳥・逸品料理・スピード・ご飯・デザート・ドリンク
[sticky] IZ / Filter Bar        44  絞り込み: アレルギー / ニガテな食材 / 受け取り方法
         IZ / Hero Band        160  写真＋明朝のコピー
         ベストセラー                見出し + Best Seller Card ×n（横スクロール）
         焼鳥                       見出し + Menu Row ×6   ← 縦リスト
         逸品料理                   見出し + Menu Card S ×4 ← 2列グリッド
         ドリンク                   見出し + Menu Row ×4   ← 縦リスト
[fixed]  IZ / Staff Call Button      左下
[fixed]  IZ / Bottom Cart Bar    76  カート6点 / ¥2,800 / 注文へ進む
```

**セクションごとにカードの型を変える**のがこのテンプレの核。
焼鳥・ドリンク（品数が多く写真差が小さい）は88pxの行、
逸品料理（写真で選ぶ）は2列グリッド。

### 商品詳細

既存 `ItemDetailOverlay` の構成をそのままなぞっている。

```
         KV 390×260 ＋ 右上に IZ / Close Button
         intro    px16 / pt40   タグ → 明朝の商品名 → 説明文
         サブ画像  300×300 中央（2枚目の画像がある商品のみ）
         縦動画    342×608 中央（動画がある商品のみ）
         RECOMMENDED  IZ / Section Heading + Best Seller Card ×n
[fixed]  IZ / Bottom Detail Bar  80  カートアイコン / ステッパー / カートに入れる
```

カフェ版との差は、タイトルを中央寄せ→**左寄せの明朝**にしたことと、
下部バーを白地→**墨地**にしてテンプレ全体で「操作は墨の帯の上」というルールを通したこと。

| scrollspy タブ | 白地 50px | 墨地 44px |
| 絞り込みバー | そのまま | 高さを44pxに |

## 7. 残っている論点

### 確認が必要
- **商品詳細に価格が無い**。既存の `ItemDetailOverlay` にも Figma の Product Detail にも
  価格表示が無いため、テンプレートでも入れていない。一覧に価格を出している以上、
  詳細にも欲しいはず。入れるなら既存テンプレート側の仕様変更になる

### 今回スコープ外（機能追加になるもの）
販売用パッケージとして別途検討が必要。テンプレート切り替えでは吸収できない。

- **オプション選択**（タレ／塩、割り方、トッピング）… 居酒屋・ラーメンでは必須
- 飲み放題の残り時間・ラストオーダー通知
- 割り勘 / 個別会計
- 多言語（日英中韓）
- 注文履歴からのワンタップ再注文（`/history` はあるが再注文導線はない）
- ベストセラーの順位・注文数の表示（現状ランキング機能そのものが無い）

### デザイン上の未処理
- 写真は暖色グラデーションのプレースホルダ。生成プロンプトは
  [`docs/template-izakaya-image-prompts.md`](./template-izakaya-image-prompts.md) にまとめた
- メニュー名・価格は公式サイトの情報をもとにしたモック内容。実装前に要確認
- 未作成の画面: カテゴリ一覧 / メニュー / カート / 注文完了 / スタッフ呼出シート

### テンプレート機構そのものの論点
- 「テンプレート」が持つ差分は **(a) カラーモード (b) タイポ (c) レイアウト（カードの型）** の3層。
  (a)(b) は Variable Mode / Text Style で切り替えられるが、
  **(c) はコンポーネントそのものが違う**。実装では「カテゴリごとに表示形式（行 / グリッド）を選ぶ」
  設定を管理画面に持たせる形が現実的で、これはテンプレ切替とは独立した機能になる
