## 管理画面

### ナビゲーション構成

```
メニュー
├ メニュー管理
├ カテゴリー管理
└ 絞り込み        ← 新規
```

### 「絞り込み」画面の構成

**Top Bar**

- タイトル「絞り込み」
- 「＋ カテゴリーを追加」ボタン

**機能全体のオン/オフ**

- この店舗で絞り込み機能を使うかどうかのトグル
- オフのとき、以下の設定エリアはグレーアウト（消さない。設定内容は保持する）

**リスト**

- カテゴリー行 × N
  - ⠿ ドラッグで並び替え
  - 公開/非公開トグル
  - 編集 / 削除
  - 行を開くと、そのカテゴリーに属する項目が並ぶ（同様に並び替え・編集・削除）
- 空状態：カテゴリーが1つも無いとき

**編集パネル（Slide Panel）**

- カテゴリー名
- 説明文（任意）
- 公開トグル
- 項目の追加・編集・削除
- キャンセル / 保存する

**削除確認モーダル**

- カテゴリー削除時、配下の項目もまとめて消える旨を明示

### 固定カテゴリーと自由追加の扱い

| | 固定カテゴリー | 店舗が追加したカテゴリー |
|---|---|---|
| 初期配布 | あり（全店舗に同じものを配る） | なし |
| 削除 | **不可**（オフにはできる） | 可 |
| 名称変更 | 不可 | 可 |
| 項目の増減 | 可 | 可 |

**固定カテゴリー（初期案）**

- アレルギー
- 苦手な食材

**アレルギーの初期項目（要確認）**

食品表示法の特定原材料に準拠させる想定。
**リリース前に最新の指定品目を必ず確認すること。**（法改正で品目が変わる）
