# ブランドカラー（テーマカラー）の設定

**状態: 仕様案（2026-09-07、天真の確認待ち）。** 決めてほしいことは末尾「8. 決めてほしいこと」。

---

## 1. 何を作るか

1. YORKYS BRUNCH のモバイルオーダーに、リニューアル後のキービジュアルの **モスグリーン** を入れる（紙のメニューと合わせる）。
2. 今後の店舗展開に向けて、**店舗ごとのブランドカラーを管理画面で設定できる**ようにする。

---

## 2. 今の仕組み

- 色は `app/design-tokens.css` の CSS 変数。**ブランドで差し替えるのはアクセントの4色だけ**という設計
  （`accent/primary` `accent/pressed` `accent/deep` `accent/subtle`。墨地用の `accent/on-ink` と `bg/warm` も実質セット）
- Figma の Color コレクションには **YORKYS（黄）／ Demo (Green)（明るい緑 #35B37E）／ Izakaya（赤 #C4302A）** の3モードがある
- ただし実装は YORKYS の黄で**固定**。店舗ごとに切り替える仕組みはまだ無い
- **黄のアクセントの上の文字は黒**（10.5:1）。モスグリーンのような暗い色では白文字にする必要があり、
  「アクセントの上の文字色」のトークン（`accent/contrast`）を1つ足す必要がある（ボタン・チップ・セグメントの文字がこれを使う）

---

## 3. モスグリーンの候補

添付画像の緑は **#5E6B4A 前後**（カラーコード未指定のため推定）。白文字が読める濃さの範囲で5つ。

| 候補 | primary | 白文字 | 黒文字 | 印象 |
|---|---|---|---|---|
| **M1 オリーブモス** | #5E6B4A | 5.7:1 ✅ AA | 3.1 | 画像にいちばん近い。落ち着いた緑 |
| **M2 ディープモス** | #4F5D3C | 7.1:1 ✅ AAA | 2.5 | 少し深い。ボタンの文字がはっきり |
| M3 フォレストモス | #465535 | 8.0:1 ✅ AAA | 2.2 | かなり深い。墨に近づく |
| M4 セージモス | #6B7A56 | 4.6:1 ✅ AA（ぎりぎり） | 3.8 | 明るく柔らかい。小さい文字は注意 |
| M5 カーキモス | #6A6E45 | 5.3:1 ✅ AA | 3.3 | 黄みが強い。紙の質感寄り |

AI の推奨: **M1**（画像に忠実）。ボタンの文字を白にする前提。派生色（pressed / deep / subtle / on-ink / bg-warm）は候補ごとに機械的に作る（`.claude/verification/2026-09-07-brand-color/` の板を参照）。

### 3-1. 幅を広げた版（2026-09-08、天真の指摘「5色が似すぎ」を受けて）

`.claude/verification/2026-09-08-brand-color-wide/brand-color-wide.html` に15色。3つの帯で振った。

| 帯 | 作り方 | 文字 |
|---|---|---|
| **A 色相だけ変える** | YORKYS イエロー（#FAC03D、彩度95%・明度61%）の色相を 60°〜120° にずらす（レモン／ライム／イエローグリーン／グラス／グリーン） | 黒のまま（黄と同じ扱い。実装の変更が最小） |
| **B 鮮やかな中明度** | 彩度50〜55%・明度36〜42%（オリーブ／モスビビッド／リーフ／フォレスト／エメラルド寄り） | 白 |
| **C モス** | 前回の M1 を基準に、彩度と色相を振る（モス＋彩度／ディープモス＋彩度／カーキ寄り／ダークフォレスト） | 白 |

紙のメニューのモスグリーンに寄せるなら C か B の左寄り、黄色のときの「元気さ」を残すなら A。
A だけは文字が黒のままで済むので、`accent/contrast` トークンの追加が要らない（切替の実装が軽い）。

### 3-2. 後で入れたいこと（天真のメモ、2026-09-08）
- カスタムカラーに**カラーピッカー**を付ける
- 読みにくい色を選んだときは、警告だけでなく**実際にプレビューで見せる**

---

## 4. 店舗ごとの設定（管理画面「表示設定」に「ブランドカラー」を追加）

- **プリセット**: YORKYS イエロー／ モスグリーン／ 居酒屋レッド／ デモグリーン をスウォッチで選ぶ
- **カスタム**: HEX を1つ入力（またはカラーピッカー）。派生の4色と「文字は白か黒か」を自動で決める
- **プレビュー**: ボタン・タブ・チップ・セグメント・カートのバッジをその色で表示
- **読みやすさの警告**: 白でも黒でも 4.5:1 に届かない色は「文字が読みにくくなります」と出して保存できない（or 警告だけ）
- 保存先: `stores.brand_accent`（HEX 1つ）＋ 派生はコードで計算（保存しない）。
  移行前は NULL ＝ YORKYS の黄（今のまま）

## 5. お客様側での反映

- 店舗ページの最初の読み込みで、サーバー側が店舗の色を読んで `<style>` で CSS 変数を上書きする（黄が一瞬見えてから緑になる「ちらつき」を避けるため）
- Figma は Color コレクションに **モード「YORKYS Moss」** を足す（既存 YORKYS モードは残す）

---

## 6. 影響範囲（実装時）

- `app/design-tokens.css`: `--color-accent-contrast` を追加。ボタン・チップ・セグメント・バッジで黒文字を決め打ちしている箇所をこの変数に
- `app/layout.tsx`（または店舗レイアウト）: 店舗の色を読んで変数を上書き
- 管理画面「表示設定」: ブランドカラーのカード
- SQL: `stores.brand_accent text` ＋ 保存 RPC（HEX の形式検査）

---

## 7. 決めない（今回の範囲外）

- 背景色（bg/warm）以外の全体トーン変更、フォントの変更、墨地テンプレート（居酒屋）への切替 UI

---

## 8. 決めてほしいこと

1. **モスグリーンの候補**: M1（推奨）／ M2／ M3／ M4／ M5
2. **YORKYS の切替時期**: リニューアルと同時に本番の色をモスグリーンにする／ まずプレビューで見てから
3. **管理画面の設定 UI**: プリセット＋カスタム HEX（推奨）／ プリセットだけ／ カスタムだけ
4. **読みにくい色の扱い**: 保存できない（推奨）／ 警告だけ出して保存できる
5. **白文字への切替**: 色から自動判定（推奨）／ 店舗が「文字は白／黒」を選ぶ
