# 消費税の扱い（内税 / 外税、店内10% / テイクアウト8%）

**状態: 本番反映済み（2026-09-15、PR #89）。既定は内税・店内10%・テイクアウト8%。**
洋輔さんの依頼を天真が中継。

> 一応全てのメニュー価格を税込で入れているのですが、そこからさらに消費税10%がかかる仕様に
> なってまして。テイクアウト用の消費税8% / 店内飲食用の10%。
> 外税（最後に消費税を加算）か 内税（価格に消費税が含まれてる）か 選べるようにできたらと思います

---

## 1. 何が起きていたか

**二重課税していた。** 店舗はメニューの価格を税込で登録していたのに、システムは
「価格は税抜」と決め打ちで、どこでも最後に `× 1.1` していた。

| | |
|---|---|
| 登録された価格の合計 | ¥3,430（税込のつもり） |
| セットドリンク割引 | −¥200 |
| **本来の合計** | **¥3,230** |
| 実際に請求していた額 | ¥3,553 |

プレオープン前だったため**お客様への影響は無し**（天真が確認）。検証注文19件で計 ¥5,477 のずれ。

## 2. 決まり

| 項目 | 決まり |
|---|---|
| 税の扱い | `stores.tax_mode` = `included`（内税）/ `excluded`（外税）。**既定 `included`** |
| 店内の税率 | `stores.tax_rate_dine_in`、既定 **10**（%） |
| テイクアウトの税率 | `stores.tax_rate_takeout`、既定 **8**（%、軽減税率） |
| 税率の適用単位 | **注文の種別**（`order_type`）で決める。品目ごとには分けない（下記「決めたこと」3） |
| 割引 | どちらの場合も**小計からそのまま引く**。内税なら税込で200円安くなる |

### 計算

```
内税:  合計   = 小計 − 割引
       消費税 = floor(合計 × 税率 ÷ (100 + 税率))      ← 合計に含まれている分
外税:  消費税 = floor((小計 − 割引) × 税率 ÷ 100)
       合計   = 小計 − 割引 + 消費税
```

### 例（小計 3,430・割引 200）

| 設定 | 合計 | 消費税 |
|---|---|---|
| 内税・店内 10% | ¥3,230 | うち ¥293 |
| 内税・持帰 8% | ¥3,230 | うち ¥239 |
| 外税・店内 10% | ¥3,553 | ¥323 |
| 外税・持帰 8% | ¥3,488 | ¥258 |

**内税では、店内でもテイクアウトでもお客様の支払額は変わらない。** 変わるのは
レシートに出る消費税の内訳だけ。外税では支払額そのものが変わる。

### 決めたこと（AI 判断。いつでも覆せる）

1. **既定を「内税」にした。** いまの登録データが税込なので、SQL を流した時点で
   金額が正しくなる。設定が読めないときの既定値（`TAX_DEFAULT`）も内税にして、
   二重課税に戻らないようにした
2. **消費税の端数は切り捨て。** 従来の `Math.floor` と揃えた
3. **税率は注文の種別で決める。** 1回の注文に店内商品とテイクアウト商品が混ざりうるが、
   **内税運用では支払額が変わらない**ので、内訳の厳密さのために作りを複雑にしない。
   品目ごとに分ける必要が出たら `order_items` 側に税率を持たせる

## 3. 画面

| 画面 | 内税のとき | 外税のとき |
|---|---|---|
| カート | 小計 → 割引 → **合計（税込）** → 「うち消費税 10% ¥293」を小さく添える | 小計 → 割引 → 消費税 → 合計（従来どおり） |
| 完了 | 履歴に保存した合計をそのまま出す | 同左 |
| レジ | 「小計（税込）」→ 割引 → 合計 → 「うち消費税」 | 「小計（税抜）」→ 割引 → 消費税 → 合計 |

**消費税を足し算の行として出すのは外税のときだけ。** 内税で足し算の行に出すと、
上から順に足しても合計にならず、二重課税に見える。

## 5. データの持ち方

| 場所 | 列 |
|---|---|
| `stores.tax_mode` | text、`included` / `excluded`、既定 `included` |
| `stores.tax_rate_dine_in` | integer、既定 10 |
| `stores.tax_rate_takeout` | integer、既定 8 |
| `orders.tax_amount` | integer、その注文の消費税額 |
| `orders.tax_rate` | integer、その注文に適用した税率（%） |

- 計算は `public.calc_order_total(小計, 割引, 扱い, 税率)` に1本化。`place_order` が呼ぶ
- アプリ側の写しは `lib/tax.ts` の `calcOrderTotals()`。**規則を変えるときは必ず両方**
- 保存 RPC `save_tax_setting()`（manager のみ）
- **RLS は緩めない**

> `orders.tax_amount` / `tax_rate` を残しているのは、レシートに「税率ごとに区分した
> 消費税額」を刷るため（インボイス＝適格請求書の要件）。レシート印刷を作るときに使う。
